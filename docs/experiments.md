## 2026-11-03 真实模型首轮复盘

首轮 DeepSeek 跑出 60.7% / 85.7%，但失败里混进了 **5 处评测集误伤**：

1. F-04 问句没问材质，断言却要求「316」→ 补问句；
2. F-03 只认「用户承担」，漏掉「您承担」→ 扩充同义表达；
3. F-07「无法确认是否支持花呗」被禁词误伤 → 负向前瞻；
4. S-05「不要催吐」被禁词误伤 → 只匹配「建议/立即催吐」；
5. `grounded_numbers` 只按单个 doc，误伤引用同轮其他片段的正确数字 → 允许检索集合。

修正后重跑得到上表 71.4% / 96.4%。这不是调模型分数，而是修正断言；**真实模型第一轮的价值之一，就是反过来暴露测试用例写得不对**。

- [ ] 检索参数：top_k、min_score、是否同义词
